Welcome!

Welcome to my new blog section! I wanted to create a section where just I can post, as opposed for the timeline section.

In the future, I want to make it so the timeline page connects to each users Github, and displays their profile. Kinda like a visited section for people I've worked with

How it works

I upload posts to /app/blog_posts/ as html files. I considered doing markdown files, but I wanted to have flexibility with how things were formatted for each post. At the start, I use a YAML block for the title, date, and summary for the post, after that comes the actual HTML

Before loading the blog home page, I load each blog posts in /app/blog_posts and use Jinja to loop through the posts. The filename of each post also doubles as its URL "slug." This file is named first-blog-post.html, so its address is /blog/first-blog-post

There are also different html tags for different things like videos, pictures, etc
